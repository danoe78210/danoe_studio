# Kindle Previewer Portable

Placez ici les fichiers de Kindle Previewer 3 ou 4 pour la version autonome.

Téléchargement : https://kdp.amazon.com/kindle-previewer

Dossier attendu (exemple) :
  bin/kindle_tools/KindlePreviewer3.exe      (v3)
  bin/kindle_tools/kindlepreviewer4.exe      (v4 via Windows Store)

Le générateur KPF cherche automatiquement ces emplacements.
