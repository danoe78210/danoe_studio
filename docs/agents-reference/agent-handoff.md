# Handoff inter-agents

Transmettre uniquement cet objet, sans recopier le depot ni le prompt complet :

```yaml
objectif: resultat concret attendu
fichiers:
  - chemin utile
contraintes:
  - contrat ou comportement a preserver
validation:
  - commande ou verification attendue
sortie: format et niveau de detail attendus
```

L'agent receveur lit ensuite le code et la reference specialisee necessaire.
