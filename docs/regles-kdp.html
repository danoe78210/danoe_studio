Les marges sont symétriques (gauche = droite) pour garantir la conformité KDP.

Marges extérieures

  • Minimum requis : 0.25 po (6.4 mm)
  • Implémentation : gouttière + 0.125 po (toujours ≥ 0.25 po)

🖼️ Images et illustrations

Gestion automatique pour garantir la qualité d'impression

  • Résolution : 300 DPI minimum
  • Format : PNG en niveaux de gris (N&B)
  • Redimensionnement automatique selon format du livre
  • Largeur max : format − 4 cm
  • Hauteur max : format − 3.8 cm
  • Centrage horizontal automatique
  • Cache HD pour éviter le re-traitement
